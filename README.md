## Solution Approach

Where appropriate, individual solutions may include:

- **Problem reference** — a link or brief description of the problem
- **Approach / intuition** — the reasoning behind the chosen method
- **Implementation** — the solution code itself
- **Time complexity** — the asymptotic runtime of the approach
- **Space complexity** — the auxiliary space used

The level of explanation will vary depending on the problem — some solutions will be brief and self-explanatory, while others will include a fuller walkthrough.
